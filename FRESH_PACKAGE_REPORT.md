# Frischpaketprüfung 2.8.3-rc23

Der vollständige RC22-Projektstand wird deterministisch aus `RELEASE_MANIFEST.json` paketiert. Die Freigabeprüfung umfasst eine frische Entpackung außerhalb des Arbeitsverzeichnisses, Versions-, Text-, Registry-, Architektur-, Qualitäts-, Test-, Coverage- und Manifestprüfung. Das Paket bleibt Release Candidate, solange die externen und physischen Stable-Gates offen sind.
