# VideoBatch Fast 2.8.3-rc24 starten

Dieses ZIP enthält das vollständige Projekt und keine Teilaktualisierung.

## Standardstart

```bash
chmod +x videobatch.sh
./videobatch.sh
```

Der Startpfad prüft Laufzeit, Projektzustand und benötigte Verzeichnisse. Qualitätswerkzeuge blockieren den normalen Programmstart nicht.

## Neue Fehlerlösung

Tritt beim Produktionsstart ein Problem auf, erscheint kein reines Informationsfenster. VideoBatch bietet passende Aktionen an, beispielsweise:

- neuen Ausgabeordner erstellen
- anderen Ausgabeordner wählen
- sicheren Standardordner verwenden
- Audios oder Medien ergänzen
- fehlende Einträge entfernen
- Diashowmodus automatisch aktivieren
- vergessene Einstellungen reparieren
- Projektordner erstellen oder Aufräumen für diesen Lauf deaktivieren

## Medien mehrfach sammeln

Im großen Medienbrowser:

1. Dateien markieren.
2. Vorschau des zuletzt angeklickten Eintrags kontrollieren.
3. „Auswahl übernehmen + im Ordner bleiben“ drücken.
4. weitere Dateien oder andere Unterordner auswählen.
5. erst am Ende „Fertig“ drücken.
