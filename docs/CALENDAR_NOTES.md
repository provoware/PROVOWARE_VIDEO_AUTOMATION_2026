# Kalendernotizen

## Datenvertrag

```json
"calendar_notes": {
  "2026-08-02": {
    "note": "Release prüfen",
    "entry_type": "deadline",
    "color": "warning"
  }
}
```

## Typen
- `note`
- `task`
- `reminder`
- `deadline`

## Farben
- `none`
- `success`
- `warning`
- `error`
- `info`
- `active`

Alte Projektdateien mit ausschließlich `calendar_marks` werden automatisch in den neuen Vertrag überführt.
