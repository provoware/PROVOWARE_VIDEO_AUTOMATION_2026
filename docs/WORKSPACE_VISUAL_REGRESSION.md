# Visuelle Regression des Arbeitsbereichs

## Ziel
Nicht nur das Startdashboard, sondern auch die produktiven Arbeitszustände gegen unbemerkte Layoutfehler absichern.

## Szenarien
- Dateiliste und Zuordnung
- Medienvorschau
- Playlist
- Produktionsmonitor

## Prüfungen
- Pflichttexte vorhanden
- Widgets innerhalb der Fenstergrenzen
- definierte Fenstergröße erreicht
- Bildvergleich gegen Referenz
- dHash-Abweichung innerhalb der Grenze
- keine automatische Referenzübernahme
