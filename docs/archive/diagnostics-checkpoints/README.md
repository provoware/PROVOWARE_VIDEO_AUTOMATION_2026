# Archivierte Diagnose-Checkpoints

Dieser Ordner enthält historische Diagnose- und Gate-Nachweise aus früheren Entwicklungscheckpoints.

## Herkunft

- `diagnostics/checkpoint2/`
- `diagnostics/checkpoint3/`

## Status

Diese Dateien sind **historische Evidence**. Sie werden von keinem aktuellen Laufzeit-, Test-, Release- oder Diagnosepfad referenziert.

Sie wurden aus dem aktiven `diagnostics/`-Bereich hierher verschoben, damit:

- aktive Diagnostik nur aktuelle Werkzeuge und aktuelle Evidence enthält,
- historische Nachweise erhalten bleiben,
- keine Löschung von Entwicklungsbelegen erfolgt,
- der Releasevertrag unverändert bleibt.

Der gesamte Pfad `docs/archive/` ist im Release-Dateivertrag ausgeschlossen.
