# Historische Layout-Referenzen

Diese beiden Bilddateien stammen aus frühen Design-/Orientierungsphasen. Im aktuellen Quellcode,
in Registries und in der aktiven Dokumentation gibt es keine direkte Referenz auf ihre früheren
Root-Pfade.

Sie bleiben aus Gründen der Nachvollziehbarkeit unverändert erhalten, liegen aber bewusst unter
`docs/archive/` und werden durch den Release-Dateivertrag sowie `.gitattributes export-ignore`
nicht mehr in Benutzer-/Source-Archive aufgenommen.
