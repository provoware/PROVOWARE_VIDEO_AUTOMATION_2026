# Historische Release-Nachweise

Dieser Ordner enthält frühere RC-, Qualitäts-, Implementierungs- und Auditberichte. Sie bleiben für Nachvollziehbarkeit erhalten, gehören aber nicht zum aktiven Releasevertrag und werden aus Portable-, Stable- und Releasepaketen ausgeschlossen.

Aktuelle freigabefähige Nachweise liegen im Projektstamm und tragen den Zusatz `_save_`. Der maschinenlesbare Status steht in `RELEASE_FILE_STATUS.json`.

## Inhalt

- frühere `CODE_QUALITY_REPORT_*`
- frühere `IMPLEMENTATION_REPORT_*`
- frühere `FINAL_AUDIT_*`
- frühere `VideoBatch_Fast_*_BUILD_REPORT.json`
- vollständiger Changelog vor der Finalbereinigung
